# Pokemon theme for Eitr

A dark [Eitr](https://eitr.info) theme with Pokemon art: Pikachu yellow on night indigo, with 4 wallpapers.

![Preview](pokemon/preview.png)

## Install

Open the Eitr Store, choose Themes, and search for Pokemon.
